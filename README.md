# Telegram Ads Platform

A platform for managing ad campaigns inside Telegram.

> The source code of this project is private. This page describes what it does and how it is run.

## Components
- **Telegram bot** - the main entry point for users.
- **Telegram Mini App** - the in-app interface.
- **Web admin panel** - for administrators to manage the platform.
- **Payment module** - handles payments for campaigns.

## How it is run
- Runs on a Linux server with scheduled jobs and monitoring.
- Delivered and handed over with project documentation.

## Context
Built at Arika (2024 - 2026) as one of five production services I delivered and handed over.
